## Comparison

Python and Java extensions mainly improve language-specific coding by adding syntax support, IntelliSense and Run/Debug features. Prettier changes the editing experience by automatically normalizing indentation, spacing and formatting. GitLens focuses on version-control history by showing who changed a line and when, together with commit and file history. Live Share focuses on collaboration by allowing two students to edit the same file and see each other's cursors in real time. For everyday projects, language extensions can be enabled according to the language being used, while formatting and Git history tools can be useful across many projects. Live Share is most useful when pair programming or collaborating with another student.
